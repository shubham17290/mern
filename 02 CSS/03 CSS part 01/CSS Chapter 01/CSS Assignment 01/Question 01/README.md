# CSS Assignment 01 - Ozymandias Poem

A simple web page displaying the famous poem "Ozymandias" by Percy Bysshe Shelley with interactive comment functionality.

## 📋 Project Overview

This project is part of CSS Assignment 01 and demonstrates various CSS styling techniques while presenting the classic poem "Ozymandias". The page includes an interactive comment section where users can leave their thoughts about the poem.

## 🎯 Features

- **Poem Display**: Beautifully styled presentation of "Ozymandias" by Percy Bysshe Shelley
- **Responsive Design**: Centered layout with proper text alignment
- **Interactive Comment Section**: Users can leave comments using the textarea
- **Styled Elements**: 
  - Custom colors for different text elements
  - Underlined emphasis on key words
  - Styled buttons and links
  - Custom textarea styling

## 🛠️ Technologies Used

- **HTML5**: Structure and content
- **CSS3**: Styling and layout
- **JavaScript (ES6+)**: Interactive functionality

## 📁 Project Structure

```
Question 01/
├── index.html          # Main HTML file

```

## 🎨 CSS Features Implemented

1. **Background Color**: Wheat-colored page background
2. **Text Styling**:
   - Poem text in red color
   - Poet name in black
   - Centered alignment for headings and poem
3. **Link Styling**: Green Wikipedia link without underline (using RGB values)
4. **Button Styling**: White background with blueviolet text
5. **Textarea Styling**: Black text color using hex code (#000000)
6. **Text Decoration**: Underlined "Ozymandias" in the heading
7. **Line Height**: 30px line height for poem text

## 💡 JavaScript Functionality

The `script.js` file provides the following features:

- **Comment Submission**: Users can submit comments via the comment button
- **Comment Display**: Submitted comments are displayed on the page
- **Input Validation**: Ensures comments are not empty before submission
- **Clear Feedback**: Visual feedback for user actions
- **Persistent Storage**: Comments are stored in browser's localStorage

### JavaScript Features:
- Event listeners for button clicks
- DOM manipulation to display comments
- Local storage integration for comment persistence
- Input validation and error handling
- Dynamic comment rendering

## 🚀 How to Use

1. Open `index.html` in a web browser
2. Read the poem "Ozymandias"
3. Scroll down to the comment section
4. Type your thoughts in the textarea
5. Click the "Comment" button to submit
6. View your comment appear below the form
