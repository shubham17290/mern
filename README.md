## 📌 Overview

This repository is a **personal learning journal + codebase** for a full-stack web-development curriculum. Instead of scattered notes, every concept is captured as a small, focused, runnable file so that revision is as easy as opening a folder and reading the code.

What you'll find here:

- 🧩 **Concept-first files** — each topic lives in its own numbered folder, named after the concept it teaches.
- 📝 **Assignments & practice questions** — solved with clean, readable code.
- 🎨 **Mini-projects & clones** — real UIs (Spotify player, Travel agency template, Bootstrap pages, CSS animation projects).
- 🗺️ **Curriculum PDF** — the full AI-powered MERN roadmap that drives the course.
- ✅ **Zero tooling friction** — pure HTML/CSS/JS; open `index.html` in a browser and you're running.

## 🗺️ Learning Roadmap

The course is organised as a progressive journey from markup to full stack:

```text
   │        │
   │        ├──► Phase 3 ──► CSS frameworks (Bootstrap 5)
   │        │
   │        └──► Phase 4 ──► Mini-projects & clones (Spotify, TraveLand, …)
   │
   ├──► Phase 5 ──► JavaScript ES6+ (operators, control flow, DOM, …)
   │
   └──► Phase 6 ──► (upcoming) React, Node.js, Express, MongoDB  →  MERN
```

> 📄 The full curriculum is available as **`00 Roadmap/AI Powered MERN Stack Development Curriculum Updated.pdf`**.

## 🌟 Featured Projects

### 🎧 Spotify Clone — `02 CSS/11 CSS projects/SPOTIFY-CLONE`

A Spotify home-page clone that grew into a **fully working local music player** — built with plain HTML + CSS + JavaScript (no frameworks, no build step).

- ▶️ / ⏸️ Play-pause, previous / next track
- Clickable & draggable progress bar with live time labels
- Shuffle, repeat (off / all / one), play queue panel with animated EQ
- ❤️ Like songs persisted in `localStorage`, live "Liked Songs" entry
- Volume slider + mute, live search overlay (`Ctrl/⌘+K`), toasts, keyboard support
- MediaSession hooks (hardware media keys), responsive mobile layout, `prefers-reduced-motion`

Run it:

```bash
cd "02 CSS/11 CSS projects/SPOTIFY-CLONE"
python -m http.server 8000
# open http://127.0.0.1:8000/index.html
```

### ✈️ TraveLand — `01 HTML/03 HTML project/traveland-1.0.0`

A complete **tour & travel agency website template** (HTML + assets) used as a study of a production-grade multi-page site structure.

### 🅱️ Bootstrap 5 Assignment — `02 CSS/10 CSS frameworks/00 Assignments/project`

A hands-on project built while learning Bootstrap 5 components, grid system and utilities.

### 🎬 CSS Animation Projects — `02 CSS/08 CSS part 06/00 CSS Animations Projects`

A collection of animation-driven mini-projects exploring keyframes, transforms and transitions.

<a id="getting-started"></a>

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shubham17290/mern.git
cd mern
```

### 2. Run a lesson in the browser

Open any `index.html` (or any `.html` file) directly in your browser, or serve the folder:

```bash
python -m http.server 8000
# then visit http://127.0.0.1:8000
```

### 3. Run a JavaScript file with Node.js

```bash
cd "03 JavaScript/01 Phase 1 and 2/00 Basics"
node app.js
```

Any file can be run the same way:

```bash
node "03 JavaScript/01 Phase 1 and 2/06 Swtich statement/_02_practice.js"
```

### 4. Regenerate Spotify clone media (optional)

```bash
cd "02 CSS/11 CSS projects/SPOTIFY-CLONE"
pip install pillow numpy      # ffmpeg must be on PATH
python tools/generate_media.py
```

<a id="how-to-navigate"></a>

## 🧭 How to Navigate

- Folders are **numbered** in the order they're taught — start at `00` and move forward.
- Each concept is a **small, self-contained file** — read it top to bottom; comments explain the "why".
- Assignment/practice folders contain the **solved questions** alongside the problem statements.
- `README.md` files inside module folders (e.g. `03 JavaScript/README.md`) give module-specific deep dives.
- The `00 Roadmap` PDF is the master curriculum — use it to see what's coming next.
