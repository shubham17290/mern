# Quiz App 🧠

An interactive quiz engine with timers, scoring, and a persistent leaderboard.

## Features
- 4 categories: JavaScript, HTML, CSS, Web General (32 questions)
- 3 difficulty levels: Easy / Medium / Hard
- Configurable question count (5/10/15) and time per question (10/15/30s)
- Per-question countdown timer (auto-skip on timeout) with warning color
- Score tracking + animated progress bar
- Instant feedback with correct/wrong highlighting
- Review screen listing every answer with correct solution
- Persistent leaderboard with player name (top 10)
- Grade message based on percentage
- Dark/light theme toggle

## Tech Stack
HTML5 · CSS3 (animations, transitions) · Vanilla JavaScript · localStorage

## Setup
Open `index.html` in a browser (or serve via `python -m http.server`). No build step required.
