# Quiz App 🧠

An interactive quiz engine with timers, scoring, and a persistent leaderboard.

## Features
- Multiple categories & difficulty levels
- Per-question countdown timer (auto-skip on timeout)
- Score tracking + progress bar
- Instant feedback on answers
- Review screen with correct answers
- High-score leaderboard in `localStorage`

## Tech Stack
HTML5 · CSS3 (animations) · Vanilla JavaScript · localStorage

## Setup
Open `index.html` in a browser. No build step required.
