# Mini E-Commerce Store 🛒

A responsive storefront with filtering, sorting, cart state, and a checkout summary.

## Features
- Product grid with search, category filter, price sort
- Add to cart, quantity controls, remove items
- Cart drawer with live total + promo code
- Product detail modal & wishlist toggle
- Responsive layout + skeleton loaders

## Tech Stack
HTML5 · CSS Grid/Flexbox · Vanilla JavaScript · JSON data (or FakeStore API)

## Setup
Open `index.html` in a browser. No build step required.
