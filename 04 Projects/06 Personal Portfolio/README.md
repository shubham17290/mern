# Personal Portfolio 🌐

A clean, responsive single-page portfolio to showcase your projects and skills.

## Sections
- Hero with typing animation · About · Skills (with progress bars) · Projects · Contact
- Smooth scroll & sticky navbar with active-link highlight
- Mobile hamburger menu
- Dark / light theme toggle (persisted)
- 6 project cards with tech tags + live demo & code links
- Contact form (mailto, ready for Formspree)
- Scroll-reveal animations + back-to-top button

## Tech Stack
HTML5 · CSS3 (Grid, Flexbox, animations) · Vanilla JavaScript · IntersectionObserver

## Setup
Open `index.html` in a browser. Deploy on GitHub Pages / Netlify / Vercel.

## Customization
- Replace "Your Name", social links, email, and project URLs in `index.html`.
- Adjust skill percentages and project list to match your work.
