# Personal Portfolio 🌐

A clean, responsive single-page portfolio to showcase your projects and skills.

## Sections
- Hero · About · Skills · Projects · Contact
- Smooth scroll & sticky navbar
- Dark / light theme toggle
- Project cards with live demo + GitHub links
- Contact form (mailto / Formspree)

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript

## Setup
Open `index.html` in a browser. Deploy on GitHub Pages / Netlify / Vercel.
