# Smart To-Do ✅

A task manager with full CRUD, drag-and-drop reordering, theming, and persistence.

## Features
- Add / edit / delete / complete tasks
- Filters: All / Active / Completed
- Priority tags & due dates
- Drag-and-drop reordering (HTML5 Drag & Drop API)
- Dark / light theme toggle
- Data persisted in `localStorage`

## Tech Stack
HTML5 · CSS3 (custom properties) · Vanilla JavaScript · localStorage

## Setup
Open `index.html` in a browser. No build step required.
