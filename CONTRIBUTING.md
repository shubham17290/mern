# Contributing

Thanks for your interest in contributing! 🎉

## How to contribute

1. **Fork** the repository.
2. **Clone** your fork: `git clone https://github.com/<your-username>/mern.git`
3. Create a feature branch: `git checkout -b feat/your-feature`
4. Make your changes following the existing code style.
5. **Commit** with a clear message: `git commit -m "feat: describe your change"`
6. **Push** and open a Pull Request.

## Code style

- Use 2-space indentation.
- Keep files focused — one concept per file, matching the existing numbered-folder convention.
- Add comments explaining the *why*, not the *what*.
- Test your changes in a browser before submitting.

## Reporting bugs

Use the **Bug Report** issue template. Include steps to reproduce, expected vs. actual behavior, and screenshots if possible.

## Suggesting features

Use the **Feature Request** issue template. Describe the problem it solves and the proposed solution.

## Code of Conduct

Be kind, respectful, and constructive. Harassment or discrimination of any kind is not tolerated.
