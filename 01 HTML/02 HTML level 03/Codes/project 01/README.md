# HTML Table Sigma

A modern, animated student information table with glassmorphism design and smooth animations.

## Features

- **Glassmorphism Design**: Beautiful frosted glass effect with backdrop blur
- **Animated Background**: Gradient background with floating orbs animation
- **Smooth Animations**: 
  - Table fade-in animation
  - Row hover effects with slide and scale
  - Shimmer effect on header
  - Ripple effect on click
- **Responsive Design**: Fully responsive layout for mobile, tablet, and desktop
- **Custom Scrollbar**: Styled scrollbar matching the glassmorphism theme

## Project Structure

```
project 01/
├── index.html      # Main HTML file with table structure
├── style.css       # CSS styles with animations and glassmorphism effects
├── script.js       # JavaScript file (currently empty)
└── README.md       # Project documentation
```

## Technologies Used

- HTML5
- CSS3 (Advanced features: backdrop-filter, animations, gradients)
- No external dependencies or frameworks

## How to Use

1. Open `index.html` in any modern web browser
2. The table will automatically display with animations
3. Hover over table rows to see interactive effects
4. Resize the browser window to see responsive behavior

## Browser Compatibility

- Chrome/Edge: Full support
- Firefox: Full support
- Safari: Full support (with -webkit- prefixes)
- Requires modern browser with CSS backdrop-filter support

## Customization

You can easily customize the table by editing `index.html`:

- Add more student rows in the `<tbody>` section
- Modify column headers in the `<thead>` section
- Change the title in the `<h1>` tag

## Styling

The CSS in `style.css` includes:
- Color scheme: Purple/blue gradient theme
- Font: Segoe UI (system font)
- Animations: 9 different keyframe animations
- Responsive breakpoints: 768px and 480px
